# Privacy policy for "Hermes"

"Hermes" is a personal, self-hosted assistant used only by the owner of this site. It isn't offered to anyone else.

- **Data accessed:** Google Calendar events on calendars the owner has shared with the assistant's own Google account.
- **Use:** to read the owner's schedule and create events on the owner's request. Nothing else.
- **Storage:** the sign-in token is kept on the owner's own computer. Calendar data isn't sold, shared or used for advertising.
- **Revoking access:** remove the assistant's access at myaccount.google.com/permissions, or stop sharing the calendars.
